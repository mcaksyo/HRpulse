# PulseHR

Корпоративный сервис для проведения опросов сотрудников, сбора обратной связи и анализа вовлеченности.

Проект разработан как MVP для хакатона по ТЗ компании СКС Ломбард. Решение закрывает ключевые сценарии:
- авторизация сотрудников по номеру телефона и OTP-коду;
- создание и публикация HR-опросов;
- прохождение опросов сотрудниками;
- поддержка анонимного и идентифицированного режимов;
- базовая аналитика по опросам и eNPS;
- настройка уведомлений и заготовка под Web Push.

## Что реализовано

### Backend
- `FastAPI` API
- работа с опросами, вопросами, ответами и пользователями
- аналитика по опросам
- экспорт результатов
- маршруты для уведомлений и push-подписок

### Frontend
- `React + Vite`
- авторизация по OTP
- личный кабинет сотрудника
- HR-дашборд
- конструктор опросов
- экран прохождения опроса

## Стек

- Frontend: `React`, `Vite`, `react-router-dom`, `recharts`
- Backend: `FastAPI`, `SQLAlchemy`, `Pydantic`
- Database: `PostgreSQL`
- Queue / cache: `Redis`, `Celery`
- Infra: `Docker`, `docker-compose`

## Запуск проекта

### Вариант 1. Через Docker Compose

1. Скопируйте `.env.example` в `.env`.
2. При необходимости заполните переменные окружения.
3. Запустите проект:

```bash
docker compose up --build
```

После запуска обычно доступны:
- frontend: `http://localhost:5173`
- backend: `http://localhost:8000`
- swagger docs: `http://localhost:8000/docs`

### Вариант 2. Локальный запуск backend

Перейдите в папку `backend`:

```bash
cd backend
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

Запустите сервер:

```bash
python main.py
```

Или:

```bash
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

### Вариант 3. Локальный запуск frontend

Перейдите в папку `frontend`:

```bash
cd frontend
```

Установите зависимости:

```bash
npm install
```

Запустите dev-сервер:

```bash
npm run dev
```

Сборка production-версии:

```bash
npm run build
```

## Тестовые сценарии

Для локального Docker-стенда доступны тестовые аккаунты:
- HR: `+7 900 123-45-67`
- Сотрудник: `+7 900 123-45-68`
- Дополнительные сотрудники: `+7 900 123-45-69`, `+7 900 123-45-70`

OTP-код выдаётся backend-эндпоинтом `/api/v1/auth/send-otp` в `debug_code` для удобства тестирования.
Если backend недоступен, frontend использует демо-режим только как аварийный fallback для офлайн-презентации интерфейса.

## Основные пользовательские роли

### HR
- создает опросы;
- добавляет вопросы;
- публикует опросы;
- просматривает аналитику;
- отслеживает ответы сотрудников.

### Сотрудник
- авторизуется по номеру телефона;
- получает доступные опросы;
- проходит опрос;
- управляет личными настройками уведомлений.
